# Space Salvage — скриншоты для магазина

Статус на 20.10.2026: шесть игровых скриншотов от 14.10.2026 находятся в `screenshots/ru`, а оформленные варианты — в `Google-Play-Upload/phone-screenshots`. После этих снимков появились Fusion и награды магазина за рекламу. Подключённого устройства сейчас нет, поэтому перед загрузкой нужно сверить кадры с установленной версией 1.20.1 и при необходимости снять новые.

Снимать актуальную сборку игры на русском языке. Предпочтительный экран — 1080 × 1920. PNG RGB, без растягивания, рамок и посторонних уведомлений. Требования: https://support.google.com/googleplay/android-developer/answer/9866151?hl=en

| Порядок / имя | Экран | Описание для доступности |
| --- | --- | --- |
| 01-gameplay | Основное игровое поле с дронами и находками | Космические дроны собирают находки на орбите планеты. |
| 02-hangar | Ангар: флот и редкости дронов | Ангар Space Salvage с коллекцией дронов разных редкостей. |
| 03-collection | Коллекция космического мусора | Коллекция найденных объектов и прогресс её заполнения. |
| 04-upgrades | Магазин улучшений | Улучшения сбора и работы космического флота. |
| 05-cases | Кейсы: обычный, редкий и легендарный | Три типа кейсов для получения новых дронов. |
| 06-route | Маршрут по планетам | Космический маршрут с доступными и ещё закрытыми планетами. |
| 07-quests | Задания | Задания с целями, прогрессом и наградами. |
| 08-start | Стартовый экран | Стартовый экран игры Space Salvage. |

Открыть нужный экран в игре, затем запустить из корня проекта:

```powershell
.\tools\Capture-StoreScreenshot.ps1 -Serial 'SERIAL_FROM_ADB_DEVICES' -Name '01-gameplay'
```

Скрипт проверяет, что игра открыта, сохраняет PNG в `screenshots/ru`, не меняет прогресс и не нажимает кнопки. При соотношении сторон длиннее 2:1 он останавливается, чтобы не выдавать неподходящий файл за готовый. Перед загрузкой каждый кадр следует просмотреть: текст должен быть читаемым, окна и анимации — полностью открытыми.
