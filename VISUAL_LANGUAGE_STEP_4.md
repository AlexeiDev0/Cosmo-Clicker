# Drona Salvage — Visual Language System, этап 4

Кодовые источники истины: `AppColors`, `SpaceDesign`, `Typography`,
`MyApplicationTheme`, `CosmicButton`.

## Иерархия

- Background: глубокая космическая сцена; не используется как карточка.
- Sheet: крупная панель места/раздела, радиус 24 dp.
- Card: самостоятельный игровой объект или группа данных, радиус 16 dp.
- Control: действие, вкладка или компактный выбор, радиус 12 dp.
- Минимальная touch-зона: 48 dp.

Spacing следует общей шкале 2/4/8/12/16/24/32 dp. Нестандартные значения
допустимы только для совместимости уже собранного layout и должны постепенно
сводиться к шкале.

## Цветовые роли

| Роль | Цвет |
|---|---|
| Основное действие | `Primary` mint |
| Вторичное действие/сигнал | `Secondary` ice cyan |
| Награда | `Reward` amber |
| Опасность/ошибка | `Danger` coral |
| Common | `RarityCommon` cold silver |
| Rare | `RarityRare` cyan |
| Legendary | `RarityLegendary` violet + ограниченный amber |
| Locked | `Locked`, opacity 48% |
| Disabled | `Disabled`, opacity 52% |
| Completed | `Completed`, opacity 72% |

Семантические роли обязательны для общих компонентов. Цвет конкретного события
может дополнять их, но не заменяет состояния enabled/disabled/selected.

## Свет и поверхности

- Свет сцены идёт сверху-слева; UI использует тот же визуальный вектор.
- Glow применяется только к фокусу, активному состоянию и награде; стандартный
  радиус фокуса — 14 dp.
- Обычная рамка — 1 dp; выбранное состояние — 2 dp.
- Тени короткие и мягкие, стандартный уровень — 8 dp.
- Основной текст белый, вторичный `TextMuted`, недоступный `TextDisabled`.

## Типографика

- Display 30/34 — только главный игровой или экранный акцент.
- Headline 22/27 — заголовок крупной панели.
- Title 18/23 и 15/20 — карточки и группы.
- Body 16/24 и 13/18 — объяснения и данные.
- Label 13/16 и 11/14 — кнопки, статусы и компактные метки.
- Длинные EN/RU/ES строки должны переноситься; текст не запекается в bitmap.

## Состояния элементов

- Normal: спокойная поверхность, один тонкий контур.
- Pressed: масштаб 96.5%, без скачка layout.
- Disabled: приглушённый цвет и opacity 52%, обработчик недоступен.
- Selected/active: семантический цвет и усиленный контур; glow только при
  необходимости показать текущий фокус.
- Locked: объект остаётся узнаваемым, затемняется до 48%, компактная lock-метка.
- Completed: сохраняется читаемость, цвет `Completed`, без конкуренции с новой
  доступной наградой.

## Правило единства

Новый экран не вводит собственную палитру, набор радиусов или художественную
технику. Уникальность экрана создают сцена, главный игровой объект и событийный
акцент; кнопки, карточки, типографика и состояния остаются общими.
