# Шаг 6 — accessibility и локализационная проверка UI

Дата: 2026-09-14.

Проведен аудит Android string resources: базовый English содержит 545 строк; RU содержит все 545 ключей; ES содержит все 545 ключей. Лишних или отсутствующих ключей не найдено.

Интерактивный объект текущей планеты получил semantics role Button и состояние disabled для закрытой планеты. Рабочие дроны получили доступное описание из имени fleet config и role Button. Декоративные изображения по-прежнему имеют `contentDescription = null`, чтобы screen reader не озвучивал фон, частицы, кейс-кадры и иллюстративные награды как отдельные элементы.

В нижней навигации и листах уже присутствуют локализованные labels/descriptions и safe-area padding. Подписи навигации допускают две строки; длинные заголовки панелей используют ellipsis или прокрутку. Font sizes остаются в `sp`, поэтому системный font scale применяется.

Найденные строковые литералы в UI — символы стрелок, маркеры (`!`, `×`, `—`), номера секций и имя разработчика. Они не являются пользовательскими предложениями, поэтому отдельные localization keys для них не добавлялись. Имена дронов и некоторые названия наград приходят из игровых config и требуют отдельного продуктового решения, если их нужно переводить.
